My Local Website

A portable local development environment running on Podman containers, designed to be a clean foundation for eventually deploying to a live Kubernetes cluster.

Home About Stack

What This Is

This website runs entirely inside containers on your local machine. It's a minimal but complete web stack: an Nginx reverse proxy serving static files and proxying API requests, a FastAPI backend written in Python, and a PostgreSQL database for persistent data.

The whole thing is orchestrated with podman compose and can start automatically when you log in, thanks to a systemd user service. There's no Docker Desktop, no heavy virtualization — just rootless Podman doing its thing.

Why It Exists

The goal is simple: build a website that looks professional, runs locally, and can be deployed somewhere real without rewriting everything. Every choice here — the container layout, the TLS setup, the backend structure — is meant to translate cleanly to a Kubernetes cluster when the time comes.

Right now it's a local dev playground. Eventually it'll be a live site on the web. The pieces are already in place: resource limits, health checks, secrets management, and a backend that knows how to talk to its database.

Try the API

The backend exposes a few endpoints you can hit directly from the browser. These are real HTTP requests going through Nginx to the FastAPI service — nothing simulated. Click a button to see the raw JSON response.

Under the Hood

The stack uses three containers connected over a private Podman network. Nginx handles TLS termination with a locally-trusted certificate (generated by mkcert), so the site is HTTPS from the start. The backend talks to PostgreSQL over the compose network, and the database stores its data in a named volume that survives container restarts.

Each service has CPU and memory limits set, so nothing can accidentally consume all your resources. The backend exposes a /health endpoint that checks its database connection — exactly the kind of readiness probe a Kubernetes cluster would use.
